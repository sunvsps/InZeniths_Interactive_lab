# shared

Pieces to extract from `apps/santa-box` so the next campaign starts with them:

- 3D kit: three.js scene setup, camera that frames the object between the page's text and buttons, drag to spin 360°, tween helpers
- Share: 9:16 share-image renderer, QR, native share sheet with save-image fallback
- Sheets: "send to whom?" (names, email, reminder, discount code, price summary), payment (PromptPay)
- IN ZENITH promo card shown after the link is copied
- Base theme: fonts, buttons, panel layout; each campaign sets its own colours
